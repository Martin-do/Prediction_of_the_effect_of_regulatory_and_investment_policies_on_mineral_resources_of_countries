# Version Notes — V0.4.1 Release-Hygiene and Estimand-Clarification Update

V0.4.1 makes no changes to the panel, folds, matched samples, model specifications, bootstrap seeds, replicate counts, or scientific numerical results.

## Changes

1. `Null_Signal_Sanity_Summary.csv` annotations are now generated by `run_pipeline.py` from predeclared tolerances in `analysis_config.json`; no output column is appended manually.
2. The bootstrap estimand is labelled precisely as country-cluster resampling of frozen out-of-fold/future-period contributions, conditional on fitted predictions and excluding model-refitting variability.
3. The two ge1pct material setups are machine-flagged and qualified as supportive rather than standalone confirmatory evidence.
4. Release checksums and reproducibility reports are regenerated from the root command.
